Plataforma web desarrollada para instituciones gubernamentales que centraliza la gestión de reportes ciudadanos y facilita su seguimiento desde un único sistema. Durante mi participación, contribuí principalmente al desarrollo del Frontend y a la implementación de diferentes módulos para los operadores.

## Funcionalidades

- Gestión y seguimiento de tickets ciudadanos.
- Administración de direcciones y dependencias responsables.
- Gestión de estados y prioridades de los reportes.
- Calendario para visualizar actividades y eventos.
- Interfaz responsive para uso interno.
- Integración de inteligencia artificial para automatizar la atención inicial de solicitudes.

## Stack

**Frontend**

- React
- TypeScript
- Tailwind CSS
- Angular

**Backend**

- C#
- ASP.NET

**Base de datos**

- SQL Server

**Herramientas**

- GitHub
- Notion
- Postman
