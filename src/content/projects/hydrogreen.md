Proyecto escolar enfocado en el monitoreo de cultivos de fresa mediante sensores conectados a un sistema de recopilación de datos. La información obtenida por los sensores se enviaba a firebase y posteriormente se visualizaba en un dashboard web para facilitar el seguimiento de las condiciones del cultivo.

## Funcionalidades

- Monitoreo de las condiciones del cultivo mediante sensores.
- Envío y almacenamiento de datos utilizando firebase.
- Visualización de los datos recopilados en un dashboard.
- Consulta de información actualizada del cultivo.
- Interfaz responsive para visualizar el estado del cultivo desde diferentes dispositivos.

## Stack

**Frontend**

- Astro
- JavaScript

**Base de datos**

- Firebase

## Nota

La versión actual corresponde a un mockup de la interfaz web y no cuenta con una conexión funcional con los sensores ni con Firebase. Se presenta como una prueba de concepto del dashboard y su experiencia de usuario.
