Plataforma web desarrollada para un cliente real, enfocada en establecer su presencia digital y facilitar la gestión de su catálogo de productos. Cuenta con una landing page pública, un dashboard administrativo, gestión de imágenes y un sistema de solicitudes de cotización con notificaciones automáticas.

## Funcionalidades

- Landing Page responsive para presentar la empresa y su catálogo.
- Catálogo dinámico con productos administrados desde un dashboard privado.
- Autenticación para usuarios administradores.
- Gestión de productos: creación, edición, activación y desactivación.
- Gestión y reemplazo de imágenes de los productos.
- Solicitudes de cotización con almacenamiento seguro.
- Envío automático de notificaciones por correo electrónico.
- Arquitectura modular preparada para futuras funcionalidades.

## Stack

**Frontend**

- React
- TypeScript
- Tailwind
- React Hook Form
- Zod

**Backend**

- Supabase
- Cloudflare Workers

**Servicios**

- Resend
- React Email
